    The NAT Gateway trap

    The most common way a "cheap" EC2 project quietly turns into a $50 bill.

    A NAT Gateway costs more than everything else combined

    In {{ r.short }} a NAT Gateway is ${{ r.f.nat_hr }}/hour, billed for every hour it exists whether or not a single packet crosses it. That is ${{ r.f.nat_mo }}/month before the ${{ r.f.nat_gb }}/GB processing fee. It alone is more than double the entire $20 budget.

    Plenty of tutorials tell you to put your instance in a private subnet behind a NAT Gateway. For a single SSH-accessible VPS that is the wrong architecture and the wrong bill. Put the instance in a public subnet with an Internet Gateway — an IGW has no hourly charge and no per-GB charge — and control access with a security group. Tick the NAT Gateway switch above to watch the total jump.
